# Fotos de aplicación del cuestionario — EVI-01

## Estado

Esta carpeta no contiene fotografías.

Se buscó específicamente evidencia fotográfica original del proceso de
aplicación del cuestionario a los trabajadores. **No existe.** El
cuestionario se aplicó de forma **virtual**, no en una sesión presencial de
campo, por lo que no hay un momento de aplicación física del que se pudiera
haber tomado una fotografía.

## Por qué se deja constancia de esto en vez de dejar la carpeta como "pendiente"

El estado anterior de esta carpeta decía "pendiente", dando a entender que
las fotografías existían y solo faltaba incorporarlas. No es el caso: no se
trata de un pendiente de subida, sino de la ausencia real de este tipo de
evidencia para una actividad que fue virtual desde su diseño.

Conforme al mismo criterio ya aplicado en `../../../10_Autoria/correspondencia/readme.md`
y en `../../../10_Autoria/notas_campo/readme.md` ("no se crean evidencias
ficticias ni se declaran como cumplidos elementos que todavía no hayan sido
verificados"), no se incorporarán fotografías de otra actividad, de otra
fecha o simuladas para hacerlas pasar por evidencia de la aplicación del
cuestionario.

## Consecuencia para `exif_inventario.csv` (AUT-11)

Esta carpeta no aporta filas a `10_Autoria/exif_inventario.csv`: al no
existir fotografías, no hay EXIF, dispositivo ni SHA-256 que registrar. No
se trata de una fotografía con metadato faltante (como sí ocurre con otras
evidencias del proyecto), sino de la ausencia total del archivo.
