# Consentimientos de validación por walkthrough

Esta carpeta contiene los **seis consentimientos informados públicos y
enmascarados** correspondientes a las sesiones de validación por *walkthrough*
realizadas el **3 de septiembre de 2026** sobre el prototipo V2 de SIMPA.

Los documentos publicados en esta carpeta preservan la evidencia de
consentimiento de cada sesión sin exponer la identidad ni la firma manuscrita de
las personas participantes.

## Relación con las sesiones de walkthrough

Cada consentimiento corresponde al mismo código `WT-XX` utilizado por su acta
de sesión en:

`../Acta/`

La descripción metodológica completa de la validación se encuentra en:

`../readme.md`

Los hallazgos consolidados derivados de las sesiones se documentan en:

`../hallazgos_usabilidad.md`

## Independencia respecto de otras series

Los códigos `WT-01` a `WT-06` pertenecen exclusivamente a la validación por
*walkthrough*.

No deben confundirse con los códigos `ENTR-XX` empleados para las entrevistas
semiestructuradas. Cuando una misma persona haya participado en más de una
actividad del proyecto, la correspondencia entre series se mantiene únicamente
en la zona restringida para reducir el riesgo de reidentificación.

## Consentimiento y autorización de grabación

La aceptación de participación en la sesión y la autorización de grabación son
decisiones diferenciadas.

La documentación metodológica de `../readme.md` establece que una persona podía
aceptar participar en el walkthrough sin autorizar la grabación de pantalla.

Por tanto, la existencia de un consentimiento en esta carpeta no debe
interpretarse automáticamente como evidencia de que existe una grabación para
ese mismo código.

## Material original

Las versiones originales sin enmascarar no se almacenan en este repositorio
público.

Los seis consentimientos originales se conservan cifrados en el repositorio
complementario de evidencias, dentro del contenedor:

`Consentimientos_Walkthrough_Originales.7z`

La información técnica correspondiente se registra en:

`../../00_Restringido/fichas_tecnicas.csv`

La contraseña de acceso al material restringido se entrega únicamente al docente
responsable por el canal académico correspondiente.

## Limitación sobre la clasificación de perfiles

La clasificación `Técnico` / `No técnico` se conserva en este índice únicamente
para mantener la trazabilidad de la nomenclatura utilizada en los archivos.

El README principal de `Validacion_Walkthrough/` documenta una limitación sobre
la consistencia de esa clasificación. Por esa razón, este archivo no deriva
conclusiones metodológicas a partir del perfil declarado.

## Criterio de integridad

Este README documenta evidencia que ya existe.

No reconstruye consentimientos, firmas ni decisiones de participación de forma
retrospectiva. Las seis copias públicas listadas corresponden a documentos
reales y permanecen separadas de sus originales identificables para proteger la
privacidad de las personas participantes.
