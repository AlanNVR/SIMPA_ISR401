## Limitación sobre la clasificación de perfiles

La clasificación `Técnico` / `No técnico` corresponde a la utilizada durante
las sesiones y se conserva aquí para mantener la trazabilidad de los nombres de
archivo.

El README principal de `Validacion_Walkthrough/` documenta una limitación sobre
la consistencia de esa clasificación y advierte que debe revisarse antes de
interpretar resultados por estrato.

Por tanto, este índice **no utiliza la clasificación de perfil para derivar
conclusiones metodológicas adicionales**; únicamente identifica los archivos
existentes.

## Criterio de integridad

Este archivo describe evidencia ya existente y no reconstruye sesiones,
firmas ni actas de forma retrospectiva.

Las seis actas listadas corresponden a archivos reales disponibles en esta
carpeta y se mantienen separadas de sus versiones originales identificables
para proteger la privacidad de las personas participantes.
