# Correspondencia del equipo

## Estado

Esta carpeta conserva la correspondencia escrita verificable disponible para
el proyecto SIMPA.

La mayor parte de los acuerdos y decisiones internas del equipo AHMRV se
realizaron de forma verbal, ya sea durante sesiones presenciales o mediante
llamadas. Estas jornadas se encuentran registradas en
`../bitacora_sesiones.csv`.

No se reconstruye ni se simula correspondencia que no haya existido.

No debe interpretarse como evidencia de aplicación del cuestionario original,

acta formal de la organización.

## Cierre de este componente

El 16 de septiembre de 2026 se incorporó el acta de constancia de actividades
de campo, firmada por el responsable de la Palmicultora M. Con este documento,
el componente de correspondencia de la sección de evidencia de autoría (ver
`../verificacion_seccion15.md`) queda cerrado.

El acta se firmó durante el cierre del proyecto y confirma retrospectivamente
sesiones de campo ya ejecutadas; no se presenta como un documento contemporáneo
a esas sesiones.

## Distinción respecto del cuestionario

La aplicación original del cuestionario produjo 62 respuestas y no contó en su
momento con fotografías presenciales de aplicación ni con un registro
independiente de consentimiento informado individual.

Como medida correctiva, el 15 de septiembre de 2026 se realizó una sesión
complementaria real con cinco trabajadores localizables. Esta actividad se
documenta por separado mediante:

- `../../02_Evidencias/Cuestionario/Consentimiento_Complementario/`
- `../../02_Evidencias/Cuestionario/Fotos_Aplicacion/`
- `../verificacion_exif_aplicacion.md`

Las fotografías complementarias conservan metadatos EXIF verificables.

Los cinco consentimientos y fotografías de la sesión complementaria no se
vinculan con ninguna respuesta específica de las 62 respuestas originales.

## Criterio de integridad

Este archivo describe únicamente evidencia existente y verificable.

No crea correspondencia retrospectiva, no reconstruye conversaciones
inexistentes y no utiliza la sesión complementaria del cuestionario para
representar la aplicación original de las 62 respuestas.
