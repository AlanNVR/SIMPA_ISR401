# Correspondencia del equipo

## Estado

Esta carpeta no contiene documentos.

Los acuerdos y decisiones de coordinación del equipo AHMRV durante el
desarrollo del proyecto se tomaron de forma **verbal** — en las sesiones de
trabajo presenciales o por llamada, registradas en
`../bitacora_sesiones.csv` — y no a través de canales escritos (correo,
chat, mensajería) que hubieran dejado un registro documental exportable.

Por lo tanto, no existe correspondencia escrita que incorporar como evidencia
de autoría para este punto.

## Por qué se deja constancia de esto en vez de dejar la carpeta vacía sin explicación

Conforme al criterio ya establecido en `../README.md` ("no se crean
evidencias ficticias ni se declaran como cumplidos elementos que todavía no
hayan sido verificados"), no se reconstruye ni se simula correspondencia que
nunca existió. Esta nota deja registro explícito de que la ausencia de
contenido en esta carpeta es una constatación deliberada, no un punto
pendiente u olvidado.

## Evidencia relacionada

La coordinación real del equipo, aunque verbal, sí queda respaldada de forma
indirecta por:

- `../bitacora_sesiones.csv` — fecha, horario y participantes de cada jornada
  de trabajo, reconstruida a partir del historial real de Git.
- `../aporte_individual.md` — aporte verificable de cada integrante.
- El propio historial de commits del repositorio.
