
# Scripts de análisis

**Estado: pendiente — depende de que el experimento se ejecute.**

Esta carpeta alojará los scripts reproducibles (`run_all.R` o `Makefile`,
según corresponda) que generen las tablas y figuras del componente
experimental descrito en `../readme.md` (comparación de calidad de requisitos
elicitados por el equipo humano frente a un LLM).

El protocolo está diseñado y registrado (`../protocolo.pdf`), pero la
ejecución del experimento y el análisis de sus datos todavía no se han
realizado. No se sube ningún script que dependa de datos que aún no existen.
