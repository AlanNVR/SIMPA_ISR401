# Anexos de auditoría y control de cambios

Esta carpeta reúne artefactos generados durante las prácticas PE4 y PE5 que
sustentan la evolución de la línea base del ERS.

No constituyen un nuevo entregable independiente del PFC. Se conservan como
evidencia documental de las decisiones que dieron lugar al catálogo vigente de
requisitos.

## 1. Auditoría de calidad

### `AnexoA_auditoria_calidad.xlsx`

Contiene la auditoría de calidad realizada durante PE5.

Entre sus funciones se encuentran:

- consolidar los conteos base utilizados en las métricas;
- documentar la evaluación de calidad;
- registrar denominadores utilizados para RF, RNF, historias, casos de uso y
  otras métricas;
- respaldar la re-inspección del ERS después de las correcciones.

Este archivo es una de las fuentes principales para interpretar las cifras
consolidadas de PE5.

### `AnexoB_registro_defectos.xlsx`

Contiene el registro de defectos detectados durante la inspección formal tipo
Fagan.

Permite comprobar:

- los defectos identificados;
- su severidad;
- su tratamiento;
- el estado posterior a la re-inspección.

## 2. Change Control Board

### `Acta_CCB.pdf`

Acta del Change Control Board correspondiente al control formal de cambios sobre
la línea base del ERS.

Documenta la evaluación y aprobación de las solicitudes de cambio.

### `RFC-01.pdf`

Solicitud de cambio aprobada por el CCB.

### `RFC-02.pdf`

Solicitud de cambio aprobada por el CCB.

### `RFC-03.pdf`

Solicitud de cambio aprobada por el CCB.

Las tres RFC explican documentalmente la ampliación del catálogo posterior a la
línea base anterior.

## 3. Relación con el ERS consolidado

El ERS migrado desde PE5 corresponde a la línea base consolidada después del
proceso de auditoría y control de cambios.

Por esta razón, las cifras vigentes no deben reconstruirse únicamente contando
archivos o filas de versiones anteriores.

Cuando exista una discrepancia entre una cifra histórica y una cifra consolidada
de PE5, se debe consultar:

1. el ERS consolidado;
2. `AnexoA_auditoria_calidad.xlsx`;
3. el acta del CCB;
4. las RFC correspondientes.

## 4. Procedencia

Estos artefactos proceden del repositorio de la Entrega PE5 y se incorporan al
repositorio `SIMPA_ISR401` únicamente como evidencia necesaria para preservar la
trazabilidad de las decisiones de ingeniería.

No se migraron los informes ni las diapositivas completas de PE5.
